# Weight provenance and hosting

- Upstream: `torchvision/raft_large`, meaning torchvision's `raft_large` builder with `Raft_Large_Weights.C_T_SKHT_V2`, the builder's default weights. This identifier names the torchvision weights; it is not a Hugging Face Hub repository.
- Revision: `ff5fadd56d26b40647388883af1547351ea17868b765c05b27231e72dd16a322`. A file served from a URL has no commit, so the pinned revision is the SHA-256 of the checkpoint's bytes. `python tools/pin_snapshot.py` pinned it on 2026-09-25: it downloaded the file, checked that its SHA-256 starts with `ff5fadd5` (the prefix torchvision puts in the file name), strict-loaded it into the architecture, and wrote the digest and byte size into the manifest and `src/raft_optical_flow_pipeline/pipeline.py`.
- Source URL: `https://download.pytorch.org/models/raft_large_C_T_SKHT_V2-ff5fadd5.pth`, the `url` of the weights enum in the pinned `torchvision==0.29.0`; a test asserts the two agree. The same file was already the `raft_large` pretrained URL in torchvision 0.12.0.
- Training, per torchvision's weight documentation: trained from scratch, pre-trained on FlyingChairs and FlyingThings3D, then fine-tuned on a combination of Sintel, KITTI, HD1K and FlyingThings3D (clean pass). The recipe is torchvision's `references/optical_flow`.
- Weight format: a PyTorch `state_dict` saved with `torch.save` (`.pth`, a zip archive holding pickled tensor metadata). torchvision's weight metadata lists its size as 20.129 MB; the pinned file is 21,106,607 bytes.
- Manifest: `weights/raft-large-c-t-skht-v2/dimer-base-manifest.json`, format `dimer_url_snapshot`, one entry with `path`, `url`, `bytes` and `sha256`. The entry carries its byte size and SHA-256, and `totalBytes` is 21106607.
- Upstream licence: torchvision's code is BSD-3-Clause. torchvision's README states that its pre-trained models may have their own licences or terms derived from the dataset used for training, and that the user must determine whether they have permission to use a model for their use case. The five training datasets are distributed under their own terms, which this repository did not review.
- Hosting: the Git repository vendors neither the checkpoint nor its conversion (`weights/**/*.pth` and `weights/**/*.safetensors` are git-ignored). A fresh clone stages the checkpoint from the URL above and converts it on first load.
- Fresh clone: `stage_missing_files(allow_download=True)` fetches the file only if it is absent, only from the manifest URL, and only if that URL equals the package's `WEIGHTS_URL`; `torch.hub.download_url_to_file` checks the file-name prefix during the download, and `verify_snapshot()` then checks the full SHA-256 and the byte size before any load.
- Served format: safetensors. `convert_checkpoint` reads the verified `.pth` once with `torch.load(<verified file>, map_location="cpu", weights_only=True)` (which restricts unpickling to tensors and plain containers), requires a flat dict of tensors that strict-loads into the architecture, clones every tensor into contiguous CPU storage and writes `raft_large_C_T_SKHT_V2-ff5fadd5.safetensors` with `safetensors.torch.save_file` and the one-key metadata `{"format": "pt"}`. The result must hash to the pinned `CONVERTED_SHA256` `fb8ff0d40a5182172ef39b05905544559fb166901dce749e01a1d2677e44e8dd` (21,060,872 bytes, 169 tensors), or it is deleted and the conversion refused. The conversion is byte-reproducible: two conversions on 2026-10-24 gave the same digest.
- Loader trust boundary: `raft_large(weights=None, progress=False)` builds the architecture without downloading anything; `verify_converted` checks the safetensors digest and `load_state_dict(load_file(<conversion>), strict=True)` refuses a missing, unexpected or mis-shaped tensor. The serving path never calls `torch.load`; once the conversion exists the `.pth` is not needed.
- Equivalence (2026-10-24, CPU, torch 2.14.0, torchvision 0.29.0): every one of the 169 converted tensors equals its source tensor, and on the tutorial pair `moving_shapes_pair(0)` the model loaded from the conversion and the model loaded from the `.pth` with `weights_only=True` returned identical flow fields (`numpy.array_equal`, max abs difference 0.0; EPE 0.0782 px).
